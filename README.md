## 📖 About This Repository

This is my **daily problem-solving log** while building a strong foundation in Python for data science. Each `DAY` folder represents one practice session — working through NumPy, Pandas, data manipulation, and small applied projects, building up in difficulty over time.

No shortcuts, no skipped days that I can help — this is where consistency turns into competence.
